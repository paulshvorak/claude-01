## Інструменти Claude Code

### CLAUDE.md
Пам'ять і правила проєкту. Пиши стисло, бо файл щоразу з'їдає контекст.

**Застосування:**
Створили `CLAUDE.md` з конвенціями проєкту (де секрети, контракт джерела, архітектура).

### Skills
Спершу завантажується лише опис, повний вміст — при виклику. Тож головне — точний опис, за яким Claude вирішує, коли скіл брати.

**Застосування:**
—

### Hooks
Детерміновані дії на події. Промпт — це прохання, хук — гарантія.

**Застосування:**
`PreToolUse`-хук на `Bash` (`.claude/settings.json` + `scripts/check_no_secrets.py`) блокує `git add`/`commit`, якщо застейджений `.env` або значення токена бота опинилось у diff. Перевірено: форс-стейджений `.env` блокується (exit 2), звичайний коміт проходить.

### Subagents
Ізольовані виконавці. Субагент має повертати стиснений результат, а не сміття в основний контекст.

### MCP
Підключення зовнішніх сервісів. Кожен інструмент роздуває контекст, тож підключай лише потрібне.

**Застосування:**

### Permissions і settings
Що агентові дозволено без питань і де це налаштовано. Рівні мають ієрархію: managed > user > project > local. У headless-режимі нікому натиснути «дозволити».

### Headless і Agent SDK
`claude -p` для запуску без чату. Agent SDK — це цикл агента Claude Code як бібліотека для TypeScript і Python, щоб вбудувати агента у свій сервіс.

**Застосування:**
`report.build_instagram_digest` — перший реальний `claude -p` виклик (subprocess, `--model claude-haiku-4-5-20251001`): підсумок з підписів постів. Без жодних tool-permissions — чисте перетворення тексту, моделі нема чим скористатись. Є фолбек (простий список без підсумку), якщо виклик впаде.

## Рівень API

### Вибір моделі
Opus, Sonnet, Haiku — не «кращий і гірший», а інструменти для різних кроків.

**Застосування:**
Haiku для Instagram-підсумку (формулювання, не складне рішення — дешево). У Threads-пайплайні розділили по кроках: Haiku шукає теми (механічна робота), Sonnet пише фінальний опис (де Haiku давав калькований текст). Дорожче за токен (~$0.10 проти ~$0.06 на крок), але без артефактів — модель під конкретний крок, не одна на весь пайплайн.

Опис, назва й схема tool — це API для моделі. Більшість «агент тупить» означає «незрозуміло, коли брати інструмент».

## Надійність і безпека

### Prompt injection
Агент, що читає чужі тексти, отримує в них і чужі інструкції. Що більше агент може зробити, то дорожче це коштує.

**Застосування:**
—

### Пам'ять між запусками
Що зберігати, як стискати, коли забувати.

**Застосування:**
—

### Observability
Логи, токени, вартість кожного прогону. Без цього «вартість і латентність» — гадання.

**Застосування:**
—

### Читання транскриптів
Evals показують, що зламалось, транскрипти — чому.

**Застосування:**
—

### Обробка збоїв
Ретраї, ідемпотентність, відповідь не за форматом, порожнє джерело.

**Застосування:**
`run_daily.py`: збій одного джерела (try/except) не валить прогін. Перший реальний прогін зловив два живі збої: Telegram 404 без `chat_id`, потім 400 «message is too long» на бекафілі 30 статей — обидва залоговано, не впали мовчки; другий виправлено розбиттям на кілька повідомлень. Ідемпотентність: повторний запуск одразу після — нуль дублів (`INSERT OR IGNORE` + `sent_at`).
