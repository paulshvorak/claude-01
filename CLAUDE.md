# Social Context Digest

Деталі задуму й етапів — у `docs/brief.md`. Читай його перед роботою над новим джерелом.

## Секрети
Усі токени (Telegram, Apify) — лише в `.env` (не в git). `.env.example` — шаблон з порожніми значеннями, його тримаємо в актуальному стані. Ніколи не комітити `.env` чи реальні значення токенів у код, коміти, чи приклади.

## Як додати нове джерело
1. Новий файл `sources/<name>.py`, реалізує протокол `Source` з `sources/base.py`: атрибут `name` (= назва SQLite-таблиці) і метод `fetch() -> list[Item]`.
2. `Item.payload` — довільний dict із сирими даними джерела, без вимог до форми.
3. Таблиця створюється й наповнюється через `db.py` (`ensure_table`, `insert_new`, `get_unsent`, `mark_sent`) — не писати SQL напряму в модулі джерела.
4. Збір (`fetch`) не звертається до LLM — лише сирі дані. Судження (відбір, підсумок) — окремо, в `report.py`.

## Архітектура
джерело → `fetch()` → SQLite (окрема таблиця на джерело) → `get_unsent()` → LLM-звіт (`claude -p`) → Telegram → `mark_sent()`

## Принцип
Make it exist first, make it better later. Інструмент для одного користувача — без авторизації, масштабування, зайвої абстракції.
